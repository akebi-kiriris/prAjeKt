# Frontend Styles 目錄說明

`frontend/src/styles/` 存放前端樣式資產，特別是全域樣式、第三方元件樣式或不適合直接內嵌於單一 `.vue` 檔案的樣式資源。

## 責任範圍

本目錄應負責以下內容：

1. 全域樣式資源
2. 第三方元件樣式覆寫或補充
3. 跨多個元件共享的樣式檔

以下內容不應放在本目錄：

1. 高度綁定單一元件的局部樣式
2. 與樣式無關的互動邏輯或設定

## 相鄰目錄邊界

1. 單一元件專屬樣式優先留在該 `.vue` 檔。
2. UI 結構與互動行為放 `frontend/src/components/` 或 `frontend/src/views/`。
3. 設計 token、全域 reset 或第三方樣式覆寫才適合放在本目錄。

## 維護原則

1. 元件高度專屬的樣式應優先留在對應 `.vue` 檔中。
2. 若樣式已成為大型 domain 的獨立主題，可再評估細分子目錄。
