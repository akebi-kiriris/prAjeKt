# Frontend Router 目錄說明

`frontend/src/router/` 負責前端路由註冊與頁面入口配置，是 route path、view 對應與基本守門邏輯的集中位置。

## 責任範圍

本目錄應負責以下內容：

1. route path 與 view 對應
2. 頁面切換層級的導向規則
3. 進頁前需要判斷的基本守門邏輯

以下內容不應放在本目錄：

1. 頁面細部商業邏輯
2. 大型畫面狀態管理
3. 可重用 UI 元件內容

## 維護原則

1. router 應聚焦在頁面入口與導向規則，不承擔頁面內部流程。
2. 若守門邏輯已依賴大量 domain 狀態，應重新檢查與 store 或 service 的邊界。
