# frontend/src/components

這層放可重用的 Vue component，重點是把頁面中的獨立 UI 區塊拆出來，而不是把整個頁面邏輯都塞進單一元件。

## 目前目錄

- `timelines/`: timeline domain 的主要元件群
- `__tests__/`: component 測試

## 這層應該負責什麼

- 視覺區塊與互動區塊
- 透過 props / emits 溝通的局部功能
- 可單獨理解、單獨測試的畫面片段

## 不應該放什麼

- 整頁 route 控制
- API 請求細節
- 太多跨頁共用狀態的管理

## 拆組件判斷

- 一段畫面有自己的標題、狀態、操作按鈕，通常適合拆出
- 一段邏輯可在不同頁面或同頁不同區塊重用，通常適合拆出
- 某元件的 template / script 已經明顯過長，且其中一塊可獨立命名與測試，通常適合拆出
