# Frontend Components 目錄說明

`frontend/src/components/` 存放可重用的 Vue component，目的是將頁面中的獨立 UI 區塊拆成可理解、可重用、可測試的畫面單位。

## 責任範圍

本目錄應負責以下內容：

1. 視覺區塊與互動區塊
2. 透過 props / emits 溝通的局部功能
3. 可單獨理解與單獨測試的畫面片段

以下內容不應放在本目錄：

1. 整頁 route 控制
2. API 請求細節
3. 大量跨頁共用狀態管理

## 相鄰目錄邊界

1. 若邏輯屬於整頁資料流與頁面組裝，應放 `views/`。
2. 若邏輯屬於 API 對接，應放 `services/`。
3. 若邏輯屬於跨元件共享狀態，應放 `stores/`。

## 維護原則

1. 元件拆分應以責任清楚、可命名、可測試為優先，而非單純縮短檔案長度。
2. 畫面可重用區塊應優先抽成 component，而非長期留在 view 內。
