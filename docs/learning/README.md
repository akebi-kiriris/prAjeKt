# Learning 目錄說明

`docs/learning/` 存放個人學習筆記、技術整理、面試準備、概念理解與非正式專案筆記。這裡允許比正式文件更自由，但仍要避免和專案規格混在一起。

## 責任範圍

1. TypeScript、Pytest、SQL / ORM、MCP、AI / RAG 等學習筆記。
2. 面試準備、概念整理與個人理解。
3. 針對專案經驗的學習型回顧。
4. 尚未整理成正式 reference 或 guide 的個人草稿。

## 相鄰目錄邊界

1. 正式 Phase 規劃放 `docs/phases/`。
2. 專案契約、API 與錯誤碼放 `docs/reference/`。
3. 可重複執行的流程規範放 `docs/guides/` 或 `docs/runbooks/`。
4. 長期架構原則放 `docs/architecture/`。

## 維護原則

1. learning 文件可以保留個人語氣，但檔名與主題應可辨識。
2. 若某篇學習筆記升級成正式專案規範，應移到對應正式目錄或另建立正式版本。
3. 不把尚未驗證的個人理解寫成專案規格。
4. 面試或學習內容若引用專案事實，應以目前 repo 文件或實作為準。
