# Workflows 目錄說明

`docs/workflows/` 用於存放 AI workflow、tool workflow 與跨模組操作流程文件。這類文件的重點是描述「流程如何串接」，而不是保存單一功能的詳細規劃或正式架構設計。

## 內容範圍

本目錄適合存放以下類型文件：

1. AI 能力的操作流程
2. 工具呼叫順序與輸入輸出流程
3. 跨服務、跨模組的執行編排說明
4. 具體 workflow 範例與流程圖式文檔

## 不建議放入的內容

以下內容原則上不放在本目錄：

1. 階段性規劃或實作計畫
2. 長期穩定的系統架構說明
3. API 契約或欄位查表文件
4. 純學習筆記或個人草稿

## 相鄰目錄邊界

1. 若文件重點是階段安排，應放 `docs/phases/`
2. 若文件重點是系統責任與設計原則，應放 `docs/architecture/`
3. 若文件重點是操作手冊或排障步驟，應放 `docs/runbooks/`
4. 若文件仍屬於待收斂構想，應放 `docs/future/`

## 維護原則

1. 文件標題應能直接反映流程主題與範圍。
2. 若 workflow 依賴既有 API 或工具契約，內容應與實作保持一致。
3. 若某份文件已不再描述流程，而是穩定設計說明，應移回更合適的目錄。
