## 核心原則

1. 保留必要，不做重流程。
2. 每次改動可快速驗證、可快速回復。
3. 文件只維護最小可執行版本。

---

## 本階段只做三件事

1. `PR + CI` 固定化  
- 保持「feature branch -> PR -> checks 全綠 -> merge」。

2. `Smoke test` 固定化  
- Frontend：
```powershell
cd frontend
npm run guardrails:payload
npm run build
```
- Backend（最小關鍵組合）：
```powershell
cd backend
venv\Scripts\python.exe -m pytest tests/services/test_task_service.py tests/services/test_timeline_service_conflicts.py tests/blueprints/test_tasks.py tests/blueprints/test_timelines.py
```

3. `高風險檔案先 checkpoint`  
- 大改前先開分支，波段 commit。  
- 中斷時用 `git stash push -u -m "<reason>"`。
