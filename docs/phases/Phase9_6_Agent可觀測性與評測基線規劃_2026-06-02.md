# Phase 9.6：Agent Trace-only 前置基線

> 日期：2026-06-02  
> 2026-06-12 調整：完整 evaluation / benchmark / gate 延後到 `Phase 12`，完整 observability 收斂延後到 `Phase 13`；本文件目前只保留 trace-only 前置項。  
> 目標：先讓每次 agent 操作具備最小可追蹤性，降低後續 Phase 10 理解主線與 Phase 12/13 擴充時的除錯成本。

---

## 1. 為什麼現在只先做 trace

9.5 之後 agent 會更依賴模型提案。  
但以目前 roadmap 來看，當前主線已切到 `Phase 10` 的契約再釐清與專案熟悉，現在若一次把 benchmark、報表與 gate 全部做完，會讓單人 side project 過早切進較重的工程化流程。

因此 9.6 先只做 trace：

- 讓 `plan / execute / replan` 的關鍵步驟可追
- 讓 `request_id / plan_id / error_code / duration_ms` 先固定下來
- 為後續 `Phase 12 - Evaluation` 與 `Phase 13 - Observability` 留好接點

---

## 2. 9.6 當前交付項目

1. 執行追蹤（Trace）
  - 每次 `plan/execute/replan` 記錄：
    - request_id / plan_id / user_id
    - steps（提案與實際）
    - error_code / retryable / route
    - 各節點耗時（ms）
    - 最終狀態（succeeded/failed/rejected/expired）

2. Trace 欄位定義
  - 至少固定：
    - request_id / plan_id / route / status
    - step name / step type / duration_ms
    - error_code / retryable
  - 欄位名稱先收斂一次，避免之後 log key 漂移

3. 延後項目註記
  - `Phase 12 - Evaluation`
    - 固定 benchmark 題集
    - benchmark runner
    - 報表模板
    - merge gate
  - `Phase 13 - Observability`
    - error taxonomy 收斂
    - metrics 彙整
    - trace 驗收標準擴充

---

## 3. 當前最小驗收

1. 可回答一次操作的基本問題
  - 收到哪個 request
  - 產生哪個 plan
  - 經過哪些 step
  - 哪一步失敗
  - 花了多久

2. Trace 結構一致
  - `plan / execute / replan` 不可各自用不同欄位命名

3. 不要求此階段建立成功率門檻
  - 指標、題集、gate 延後到 `Phase 12`

---

## 4. 實作清單

1. `backend/services/agent_trace_service.py`（新）
  - 專責記錄 trace（先 in-memory / file，後續可落 DB）

2. `backend/blueprints/copilot.py`
  - 為 plan/execute/replan 補 request_id 與 trace hook

3. `backend/services/copilot_service.py` / `backend/chains/agent_nodes.py`
  - 補最小 trace step 與關鍵狀態事件

4. 文件補充
  - 補一份 trace 欄位定義或使用說明
  - benchmark / 報表模板暫不在本階段建立

---

## 5. 明確延後項目

1. benchmark 題集與成功率追蹤 → `Phase 12`
2. merge gate 與回歸比較報表 → `Phase 12`
3. error taxonomy / metrics / trace 驗收擴充 → `Phase 13`

---

## 6. Done 定義

1. 每次 plan/execute 都可追蹤步驟與耗時
2. `request_id / plan_id / error_code / duration_ms` 有一致欄位
3. 可用於進入 `Phase 10` 時的主線理解與除錯
4. benchmark / gate 尚未納入此階段 done
