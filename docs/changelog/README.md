# Changelog 目錄說明

`docs/changelog/` 存放具時間序的變更紀錄、整理紀錄與歷史更新摘要。這裡偏向「發生過什麼」，不是目前仍需照做的流程。

## 責任範圍

1. 按日期整理的重要變更紀錄。
2. 已完成工作的歷史摘要。
3. 不再適合放在 phase / reference / guide，但仍值得保留的歷史脈絡。

## 相鄰目錄邊界

1. 仍在規劃或執行中的階段內容放 `docs/phases/`。
2. 仍需日常查閱的契約或 API 內容放 `docs/reference/`。
3. 仍需照步驟執行的流程放 `docs/runbooks/` 或 `docs/guides/`。

## 維護原則

1. changelog 應以日期或版本為主要索引。
2. 若內容仍是活文件，不應只放在 changelog。
3. 歷史紀錄不必追求完整重寫，但應避免和現行規範互相矛盾。
