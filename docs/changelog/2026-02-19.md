## 🔍 發現的問題

### 缺少 Token 刷新機制

**問題描述：**
在檢查 `api.js` 的攔截器時發現，系統目前**沒有實作 JWT Token 自動刷新機制**。

**現況分析：**

#### 後端 (`backend/blueprints/auth.py`)
- ✅ 登入時有產生 `access_token` 和 `refresh_token`
- ❌ **缺少 `/api/auth/refresh` endpoint** 來使用 refresh_token 換取新的 access_token

#### 前端 (`frontend/src/services/api.js`)
- ✅ Request 攔截器會自動添加 access_token
- ❌ Response 攔截器在收到 401 時，**直接清除 token 並跳轉登入**
- ❌ **沒有使用 refresh_token 自動刷新的邏輯**

**預期行為：**
```
用戶請求 → Access Token 過期 → 401 錯誤
    ↓
攔截器自動用 Refresh Token 呼叫 /refresh
    ↓
取得新的 Access Token
    ↓
重試原本的請求
    ↓
請求成功 ✓

只有當 Refresh Token 也過期時，才跳轉登入頁面
```

**實際行為：**
```
用戶請求 → Access Token 過期 → 401 錯誤
    ↓
直接清除所有 token 並跳轉登入 ❌
```

## ✅ 已完成的修改

### 1. 修改跳轉方式為 Vue Router

**檔案：** `frontend/src/services/api.js`

**修改內容：**
- 引入 Vue Router 實例
- 將 `window.location.href = '/login'` 改為 `router.push('/login')`

**原因：**
- `window.location.href` 會導致整頁重新載入（硬跳轉）
- `router.push()` 是 SPA 的正確做法，不會刷新頁面，使用體驗更好

**修改前：**
```javascript
import axios from 'axios';

// Response 攔截器
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('access_token');
      localStorage.removeItem('refresh_token');
      window.location.href = '/login';  // ❌ 硬跳轉
    }
    return Promise.reject(error);
  }
);
```

**修改後：**
```javascript
import axios from 'axios';
import router from '../router';  // ✅ 引入 router

// Response 攔截器
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('access_token');
      localStorage.removeItem('refresh_token');
      router.push('/login');  // ✅ SPA 跳轉
    }
    return Promise.reject(error);
  }
);
```

## 💡 學習筆記

### Token 刷新的關鍵點

1. **攔截器分工**
   - **Request 攔截器**：請求發出前，添加 access_token
   - **Response 攔截器**：收到回應後，處理 401 錯誤、刷新 token

2. **防止競態條件**
   - 當多個請求同時收到 401 時，需要確保只呼叫一次 `/refresh`
   - 可使用 flag 或 Promise 來控制

3. **重試機制**
   - 刷新成功後，需要用新的 token 重新發送原本失敗的請求
   - 使用 `axios(originalRequest)` 重試

4. **錯誤處理**
   - 如果 refresh_token 也過期，才跳轉登入
   - 避免無限循環（refresh endpoint 本身返回 401 時不要再次刷新）
