# 🚀 PrAjeKt AI 功能啟動指南

## ⚡ 快速啟動（完整流程）

### 步驟 1：安裝 AI 依賴（2 分鐘）

```powershell
# 1. 進入後端目錄
cd backend

# 2. 安裝 AI 依賴
pip install langchain-google-genai

# 3. 驗證安裝
python -c "import langchain_google_genai; print('✅ 安裝成功！')"
```

### 步驟 2：獲取並配置 API Key（3 分鐘）

#### 2.1 獲取 Google API Key（免費）
1. 打開瀏覽器：https://aistudio.google.com/app/apikey
2. 用 Google 帳號登入
3. 點擊「Create API Key」或「Get API Key」
4. 選擇「Create API key in new project」
5. 複製生成的 API Key（格式：`AIzaSyXXXXXXXXXXXX...`）

#### 2.2 配置環境變數
```powershell
# 如果沒有 .env 檔案，複製範例
copy .env.example .env

# 用文字編輯器打開 .env
notepad .env
```

在 `.env` 檔案中添加（或確認已有）：
```env
GOOGLE_API_KEY=你剛才複製的API金鑰
```

**重要**：
- 確保 API Key 前後沒有空格
- 確保以 `AIza` 開頭
- 不要加引號

### 步驟 3：測試 AI 功能（2 分鐘）

```powershell
# 在 backend 目錄執行測試
python test_ai.py
```

**期望輸出**：
```
==================================================
🤖 PrAjeKt AI 功能測試
==================================================
...
✅ 通過 - 環境配置
✅ 通過 - 套件安裝
✅ 通過 - API 連線
✅ 通過 - 任務生成
...
🎉 所有測試通過！AI 功能已就緒！
```

如果看到 ❌ 錯誤，請查看錯誤訊息並按照提示修正。

### 步驟 4：啟動專案（1 分鐘）

#### 4.1 啟動後端
```powershell
# 在 backend 目錄
python app.py
```

應該看到：
```
 * Running on http://127.0.0.1:5000
```

#### 4.2 啟動前端（新開終端機）
```powershell
# 在專案根目錄
cd frontend
npm run dev
```

應該看到：
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```

### 步驟 5：測試 AI 生成（3 分鐘）

1. **打開瀏覽器**：http://localhost:5173

2. **登入或註冊**

3. **創建測試專案**：
   - 點擊「新增專案」
   - 專案名稱：`電商網站開發`
   - 專案備註：`使用 Vue 3 + Tailwind CSS，包含商品列表、購物車、結帳流程`
   - 點擊「建立專案」

4. **使用 AI 生成**：
   - 點擊剛建立的專案
   - 在專案詳情中找到「✨ AI 生成任務」按鈕（紫色漸層）
   - 點擊按鈕
   - 等待 3-5 秒

5. **預覽與創建**：
   - 查看 AI 生成的 5-8 個任務
   - 勾選/取消勾選想要的任務
   - 點擊「創建選中的任務」

6. **驗證結果**：
   - 返回專案詳情
   - 確認任務已創建
   - 切換到看板視圖查看任務卡片

## ❌ 常見問題排查

### 問題 1：ModuleNotFoundError: No module named 'langchain_google_genai'
**解決**：
```powershell
pip install langchain-google-genai
```

### 問題 2：API key not configured
**解決**：
1. 檢查 `.env` 檔案是否存在
2. 確認 `GOOGLE_API_KEY=` 有填入金鑰
3. 重啟後端（Ctrl+C 然後重新 `python app.py`）

### 問題 3：點擊按鈕沒有反應
**解決**：
1. 打開瀏覽器開發者工具（F12）
2. 查看 Console 標籤的錯誤訊息
3. 查看 Network 標籤確認 API 請求
4. 如果看到 CORS 錯誤，確認後端已啟動

### 問題 4：生成的任務是英文
**原因**：AI 根據專案名稱判斷語言
**解決**：確保專案名稱和備註使用繁體中文

### 問題 5：Invalid API key
**解決**：
1. 重新複製 API Key（確保沒有多餘空格）
2. 確認金鑰沒有過期
3. 如果還是不行，到 Google AI Studio 重新生成新的 API Key
