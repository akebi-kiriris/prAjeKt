# Runbooks 目錄說明

`docs/runbooks/` 存放可照步驟執行的操作手冊，例如本地啟動、部署、資料庫遷移、排障與事故恢復。

## 責任範圍

1. 本地開發、測試、部署與環境啟動流程。
2. 資料庫遷移、回復、修復與安全操作流程。
3. 既有部署平台或服務的操作步驟。
4. 需要一步一步照做的排障指南。

## 相鄰目錄邊界

1. 開發流程規範放 `docs/guides/`。
2. 架構設計或技術決策放 `docs/architecture/`。
3. Phase 規劃放 `docs/phases/`。
4. API 或環境變數對照放 `docs/reference/`；runbook 可引用，但不要重複整份查表內容。

## 維護原則

1. runbook 必須包含明確執行步驟或判斷順序。
2. 高風險操作應寫清楚前置條件、備份點與回復方式。
3. 指令需標明執行目錄與必要環境，例如 `backend/`、venv 或 Node workspace。
4. 若步驟已不適用，應標註過時或移入歷史紀錄，不讓讀者照錯流程。
